Unreal to Unity Texture Converter

Year:
2024
Role:
Programmer
Tech:
Python
Platforms:
PC

I built a Python tool that converts texture maps from Unreal Engine's .uasset format into texture maps compatible with Unity's rendering pipelines.

The idea came from how tedious it was to convert every texture by hand in an image editor like Photoshop whenever I wanted to use Unreal Marketplace assets in a Unity project.

I couldn't find an existing tool that handled these conversions automatically, so I spent a weekend building one, and it works really well!

It converts RMA or ORM maps into HDRP mask maps and can convert textures in bulk. Opening the source .uasset files requires Unreal Engine.

If you want to save time bringing Unreal textures into Unity, the tool is available on itch.io.
