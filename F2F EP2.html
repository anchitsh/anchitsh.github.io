What I did

I led the mobile port of Fears to Fathom: Norwood Hitchhike, adapting the PC release for touch controls and a much wider range of mobile hardware.

Highlights

  • Implemented touch gestures and on-screen controls for the mobile version.
  • Optimized assets, scripts, draw calls, terrain-heavy scenes, and memory usage.
  • Used LODs, mesh combining, texture atlases, object pooling, and Addressables to target lower-end Android devices.

The mobile release was available for several months on Android and iOS before being discontinued.
