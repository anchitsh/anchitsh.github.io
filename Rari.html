House of Rari

Year:
2021
Role:
Programmer
Tech:
Unity, C#, Blender
Platforms:
WebGL

I made this demo in one month for Rari, a tech company. They asked for a WebGL demo with a sci-fi environment where users could walk around, interact with a few things, and be directed to their website.

I partnered with Rari's 3D artist on the project.

I set up the character controller, the environment, and the lighting. Then I added holographic shaders to the inner capsules and the dancing model.

Next, I set up the vault, made it interactable, and got it animating correctly, with some god rays for good measure.

I added some basic UI inside the vault that opens Rari's website in a new tab when clicked.

Finally, I built the start screen, the password screen, and the loading screen.
